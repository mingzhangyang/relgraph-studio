## Failures reproduced and corrections

1. **Package build blocked:** core's ES2022-only build could not resolve
   `structuredClone` in position write-back (`TS2304`). A module-local ambient
   declaration describes the existing Node 20+/browser host API without adding
   DOM/Node ambient dependencies, runtime code or a clone implementation.
   The existing packed-consumer test now also calls write-back on both domains
   and verifies independent ownership of nested metadata.
2. **Fresh-checkout test import blocked:** Vite mapped the root render package
   but not `@relgraph/render/skia`; CLI source tests required an absent `dist`.
   An exact source alias now matches the existing TypeScript path mapping.
   Installed consumer tests still exercise the real package exports.
3. **Incorrect diagnostic fixture:** a new empty-state test imported the
   provisional Honglou fixture, which legitimately reports `TOO_MANY_LEADS`.
   The test now uses the warning-free biology fixture. The validator and its
   warnings are preserved.
4. **MP4 metadata regression exposed by FFmpeg 7.1.5:** output codec colour
   flags alone left primaries and transfer unspecified. Reproduced separately
   with a one-frame libx264 command. `setparams` now tags converted frames as
   well as the stream. The RGBA→limited-range BT.709 matrix, CRF, frame rate
   and rendering remain unchanged; real ffprobe and round-trip tests pass.
5. **Formatting gate:** 24 files failed Prettier on the initial main. Applied
   the pinned formatter; also included `tests/timeline.test.mjs` in
   `format:write`, matching `format:check`. Twenty other changed code/test
   files were mechanically checked to equal `Prettier(main)` exactly; their
   changes have no semantic content.

## Environment preparation and remaining limits

- Default sandbox could not reach the inherited proxy or reliably run nested
  process tests. Approved outer-executor commands enabled clone, npm, Chromium,
  package consumers and export; these checks were actually executed.
- Installed Chromium with `npx playwright install chromium`. The isolated
  consumer's `--offline` install initially lacked registry packuments despite
  `npm ci` caching tarballs. Primed metadata/transitive dependencies using
  `npm install --prefix /tmp/relgraph-cache-prime --package-lock=false
  --ignore-scripts --no-audit --no-fund skia-canvas@4.0.0 @types/node@22.20.5`.
  The repository lockfile was unchanged. The isolated test still uses offline
  installation and passed; a fresh cache may require the same preparation.
- One full-suite attempt concurrent with export failed the fake-encoder child
  exit assertion (`code: null`); isolated package checks (2/2) and the subsequent
  complete suite (174/174) passed. Its transient cause was not established.
- The new browser scenarios needed test corrections for collapsed transcript
  text and waiting for a repeated filename's new load to complete. Final
  Chromium execution passes; no loader or transcript policy change was needed.
- No NVDA/VoiceOver/Orca listening session, other browser engine, macOS/arm64,
  or production typography review was performed. Automated DOM/ARIA safety and
  mutation checks do not prove assistive-technology announcement behaviour.
- No pre-existing MP4 binary baseline was stored. Export parity means unchanged
  RGBA goldens, exact worker PNGs, probed contract and lossy round-trip matching;
  it does not claim byte-identical H.264 files. Colour metadata is intentionally
  corrected. Full dark/720p films were not exported; those combinations have
  short matrix checks plus render tests.

# 《量子力学：从哥本哈根到标准模型》制作笔记

[观看成片](./quantum-history.mp4) · [打开关系图谱](./quantum-history.graph.json) · [试听配乐](./score.m4a)

这部 3 分 13 秒的竖屏短片有两个入口。想查“泡利与哪些成果有关”，可以把 JSON 拖进 RelGraph Studio，沿着关系查看不相容原理、量子统计和中微子假说。想理解“一个轨道为什么只能容纳两个电子”，可以从成片 00:40 看起。上方的轨道图画出两个方向相反的自旋箭头，下方的关系图把泡利的规则接到原子壳层。图谱支持自由探索，影片给第一次接触这些概念的观众安排了一条阅读路线。

**成片的 11,580 帧中，RelGraph Studio 直接渲染了 0 帧。** 本片使用了 Studio 的图谱与分镜格式，并用它的适配器验证数据。画面中部的人物节点、箭头和关系词，也和上下方的科学插图、标题与解说一样，由 Python/Pillow 绘制。FFmpeg 负责转场、视频编码与声画合成。

## 从一条关系到一个镜头

在图谱里，“预言”和“发现”是两条边。第七章用它们讲了一个完整的故事。

| 起点       | 关系 | 终点   | 关系从哪一年可见 |
| ---------- | ---- | ------ | ---------------- |
| 狄拉克方程 | 预言 | 正电子 | 1931             |
| 安德森     | 发现 | 正电子 | 1932             |

这两行对应 `relgraph.graph/1` 的 `source`、`label`、`target` 和 `visibleFrom`。两条线在同一个“正电子”节点相遇，观众能分清理论预言与实验证据，也能沿各自的线索回到物理学家。用在别的题材里，写边时也可以问一句：如果把“预言”换成“发现”，这句话还准确吗？需要辨清的那个动词就值得留在画面上。

分镜在 `presentation` 中另写。第七章“方程预告了反物质”从 **01:23** 播放，`durationSec` 是 13 秒，`domainAt` 是 1932 年。前者决定观众有多久读图，后者决定此时可以讲到哪项成果。`camera.fitIds` 指定 Studio 预览时要纳入取景的五个节点，也就是狄拉克、狭义相对论、狄拉克方程、正电子和安德森，`highlight.nodeIds` 标出本章重点。全图可以容纳 98 个节点和 117 条关系，这 13 秒只需要五个节点。[通用图格式与分镜字段](../../docs/GENERIC-GRAPH.md)

## RelGraph Studio、Pillow 和 FFmpeg 怎样衔接

| 制作环节       | 本片的做法                                                                                                               | 交给下一步的内容                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| 知识图谱与分镜 | 用 Python 把整理好的章节资料写成 RelGraph Studio 通用图，用 Studio 的适配器载入并校验。关系保留方向、动词和可见年份。    | 可编辑的 JSON 图谱，以及每章的标题、焦点、解说和时长         |
| 竖屏绘图       | Python/Pillow 根据同一份章节资料排版，并读取图谱中的节点类别。上方画科学示意图，中间逐步展开局部关系，下方放解说与出处。 | 1080 × 1920 的逐帧画面；轨道、自旋、谱线和粒子表各有专门画法 |
| 配乐与成片     | Python 编排乐句，用 FluidSynth 合成立体声。FFmpeg 编码各章，再按章节顺序合并视频、AAC 音轨和可跳转的章节标记。           | 60 fps 的 MP4 和可单独试听的 M4A                             |

图谱和画面最初取自同一份 Python 章节资料。导出 JSON 之后，绘图脚本仍从章节资料里取局部连线、关系词和布局，只从 JSON 读取节点类别。因此，在 Studio 里单独把“预言”改成“1931 年预言”，再运行原绘图脚本，影片仍会显示旧文字。节点名相同，无法保证后续修改会同步。

## 两轮反馈怎样改变了影片

**第一轮改了选题结构。** 初版用 48 秒、六幕从普朗克讲到贝尔实验。看得出时间先后，却很难回答“哥本哈根这群人怎样相互影响”，也缺少泡利、狄拉克与标准模型之间的线索。重写时把一个大题拆成几张有不同任务的图：00:12 先画玻尔研究所与来访者，01:08 再画概率诠释、测不准关系和互补原理，01:36 才让玻尔与爱因斯坦围绕完备性展开争论。场论部分沿强作用和电弱作用两支发展，到 02:58 汇入标准模型。这样既能讲清学派的交流，也给独立发展的理论留出了位置。

**第二轮改了观看节奏。** 14 章里原有深浅两套页面，切章时整屏明暗跳变。定稿统一用暖白纸底、墨绿人物节点和铜色成果节点，转场也淡入相同纸色。原配乐的持续低音和长音让读图显得拖沓。新版用 120 BPM 的尼龙弦吉他、马林巴与轻打击写成短句，在句尾留出空拍。画面仍给观众原有的阅读时间，轻快感来自音乐的起音和停顿。

## 下一步用 13 秒验证 Studio 的价值

Studio 已经能根据图谱中的年份、分镜和高亮设置绘制关系网络，并导出 PNG 帧、MP4 和事件文件。最值得用在下一版的能力，是让创作者在图谱里把一项关系改对一次，重新导出后，成片也随之更新。第七章 **01:23 至 01:36** 就可以验证这一点。[现有渲染与导出能力](../../README.md#export-a-film-without-a-browser) · [逐帧绘制节点、连线和标签的实现](../../packages/render/src/compose.ts)

1. **先做手机尺寸的样片。** 用现有 CLI 按帧范围导出第七章的代表帧，把关系图放到预定的画面中部。检查“预言”和“发现”能否同时读清，两条箭头能否一眼追到同一个正电子节点。根据样片决定先改取景、字号还是标签避让。
2. **让 Studio 交付可合成的关系图层。** 建议支持按目标区域的宽高布局，导出透明背景的节点、连线、标签及出现动画。Pillow 继续画上方的正负能量曲线，FFmpeg 把两层与原配乐合成。这样外部工具可以自由设计版面，图层里的每条关系都直接来自 Studio 图谱。
3. **把图层和外部动画对到同一帧。** 本次制作所用版本的 CLI 内置规格为 24 fps，影片为 60 fps。建议让预览、逐帧导出和事件文件使用同一组选定的帧率与章节起点，外部动画可以按事件时间出现。[CLI 导出选项](../../packages/cli/src/args.ts)

**样片的验收动作**是只在 Studio 中把“预言”改成“1931 年预言”，保存图谱，重新导出并合成第七章。手机画面应显示新文字，“发现”仍清晰地指向同一个正电子节点。按目标 60 fps 交付时，这一章应为 780 帧，下一章和配乐仍在原来的时间点衔接。

## 交付时核对什么

- **在图谱里检查历史时间。** 用项目的适配器载入 JSON，再核对分镜引用的节点在该章年份已经可见。格式校验能发现无效引用，史实仍要回到文献核对。
- **在导出画面里检查可读性。** 把各章抽帧并排看，能立刻发现底色不一致；再按手机尺寸看细节。标准模型粒子表里的中微子下标就曾显示为缺字方框，最后把希腊字母与下标分别排版。
- **在最终 MP4 里检查声画。** 本片 193 秒乘以 60 fps 是 11,580 帧。用 ffprobe 核对视频规格和音轨时长，把 14 个章节标记与分镜时长逐项对齐，再核对片中音轨与独立 M4A 的 AAC 数据。只看某一章的预览，发现不了合片后的时间偏移。

仓库收录了可导入 Studio 的图谱、最终影片和独立音轨。要逐帧重建这版影片，还需要当时工作区中的 Pillow 绘图脚本、字体和配乐脚本及音色库；这些制作素材未随成片入库。[本次制作的版本记录](https://github.com/mingzhangyang/relgraph-studio/pull/66/commits)
